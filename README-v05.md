AI DJ v0.5 introduces online music discovery using MusicBrainz and ListenBrainz data, while continuing to detect the currently playing YouTube Music track through Android notification access. The recommendation engine scores discovered candidates using recent-history avoidance, likes/dislikes and artist repetition penalties. YouTube Music does not expose a public third-party API for inserting the selected track into the live playback queue, so playback handoff currently opens a YouTube Music search for the chosen recommendation.
